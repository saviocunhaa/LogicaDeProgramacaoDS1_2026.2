# 🔁 Módulo 04: Estruturas de Repetição e Laços Iterativos

Automatize tarefas repetitivas dominando os laços `for` e `while`, controles de fluxo (`break`, `continue`) e contadores.

### 📋 Conteúdo do Módulo:
* 📓 [`aula_01_laco_for_e_range.ipynb`](aula_01_laco_for_e_range.ipynb) - Laço `for`, função `range()`, contadores e acumuladores.
* 📓 [`aula_02_laco_while_e_break.ipynb`](aula_02_laco_while_e_break.ipynb) - Laço condicional `while`, sentinelas e comandos `break` e `continue`.
* 📓 [`desafio_03_senha_fixa.ipynb`](desafio_03_senha_fixa.ipynb) - Bug investigativo no sistema de controle de acesso.
* 📜 [`lista_03_exercicios.md`](lista_03_exercicios.md) - Lista de 5 missões práticas com laços de repetição.

### 🎯 Objetivos de Aprendizagem:
1. Executar iterações com número definido de passos usando `for` e `range`.
2. Controlar laços com condições de parada dinâmicas via `while`.
3. Evitar loops infinitos acidentais.
4. Aplicar acumuladores para somas, médias e estatísticas.
