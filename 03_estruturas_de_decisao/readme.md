# 🔀 Módulo 03: Estruturas de Decisão e Condicionais

Neste módulo, aprenderemos a dar inteligência aos nossos programas, permitindo que o computador tome caminhos diferentes com base em condições lógicas.

### 📋 Conteúdo do Módulo:
* 📓 [`aula_01_operadores_relacionais_e_logicos.ipynb`](aula_01_operadores_relacionais_e_logicos.ipynb) - Operadores de comparação (`==`, `!=`, `>`, `<`, `>=`, `<=`) e lógicos (`and`, `or`, `not`).
* 📓 [`aula_02_condicional_if_else.ipynb`](aula_02_condicional_if_else.ipynb) - Desvios condicionais simples e compostos (`if`, `else`) e indentação.
* 📓 [`aula_03_condicional_elif_e_match.ipynb`](aula_03_condicional_elif_e_match.ipynb) - Múltiplas condições com `elif` e estrutura de seleção `match-case`.
* 📓 [`desafio_02_detetive_de_impostos.ipynb`](desafio_02_detetive_de_impostos.ipynb) - Bug investigativo no cálculo de tributos municipais.
* 📜 [`lista_02_exercicios.md`](lista_02_exercicios.md) - Lista com 5 missões práticas de estruturas de decisão.

### 🎯 Objetivos de Aprendizagem:
1. Avaliar expressões booleanas utilizando tabelas-verdade.
2. Estruturar blocos de código com a indentação obrigatória do Python (4 espaços).
3. Construir fluxos de decisão encadeados e aninhados.
4. Tratar entradas inválidas e casos de exceção lógica.
