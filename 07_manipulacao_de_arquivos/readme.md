# 💾 Módulo 07: Manipulação de Arquivos e Persistência

Aprenda a salvar dados de forma permanente no disco rígido criando, lendo e atualizando arquivos de texto (`.txt`, `.csv`) com o gerenciador de contexto `with open()` e tratando exceções.

### 📋 Conteúdo do Módulo:
* 📓 [`aula_01_leitura_e_escrita_txt.ipynb`](aula_01_leitura_e_escrita_txt.ipynb) - Context manager `with open()`, modos de abertura (`'r'`, `'w'`, `'a'`) e `try-except`.
* 📓 [`desafio_06_analise_de_logs.ipynb`](desafio_06_analise_de_logs.ipynb) - Investigação e auditoria em arquivos de logs de servidor.
* 📜 [`lista_06_exercicios.md`](lista_06_exercicios.md) - Lista com 5 missões práticas de manipulação de arquivos.

### 🎯 Objetivos de Aprendizagem:
1. Abrir, ler e fechar arquivos de forma segura usando `with open()`.
2. Compreender a diferença entre sobrescrever (`'w'`) e anexar (`'a'`).
3. Capturar exceções de arquivos ausentes (`FileNotFoundError`).
4. Iterar sobre linhas de um arquivo de texto.
