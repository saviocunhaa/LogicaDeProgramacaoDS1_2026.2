# 🐍 Aula 02: Introdução ao Python

## 1. O que é Python?
Criado em 1991 por **Guido van Rossum**, Python é uma linguagem de programação moderna de:
* **Alto Nível:** Próxima da linguagem humana (inglês legível).
* **Multiplataforma:** Roda em Windows, Linux, macOS, Android e microcontroladores.
* **Multiparadigma:** Suporta programação estruturada/procedural, orientada a objetos e funcional.
* **Interpretada:** O interpretador do Python lê e executa o código linha a linha, sem a necessidade de compilação prévia manual para binário.

## 2. O Zen do Python (Filosofia da Linguagem)
Para ler a filosofia oficial do Python, abra o terminal e digite:
```python
import this
```
* *Bonito é melhor que feio.*
* *Explícito é melhor que implícito.*
* *Simples é melhor que complexo.*
* *Legibilidade conta.*

---

## 3. Como Executamos Código Python?

1. **Via Terminal Interativo (REPL):** Digite `python` no terminal e teste comandos em tempo real.
2. **Via Script (`.py`):** Arquivos de texto salvos com a extensão `.py` e executados com `python meu_script.py`.
3. **Via Jupyter Notebooks (`.ipynb`):** Células iterativas combinando texto formatado, código e saídas visuais imediatas.
