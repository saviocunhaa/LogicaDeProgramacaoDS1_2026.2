# 🧠 Módulo 01: Noções e Fundamentos de Algoritmos

Antes de digitar comandos em uma linguagem específica, precisamos treinar nossa mente para decompor problemas e pensar de forma estruturada.

### 📋 Conteúdo do Módulo:
* 📜 [`aula_01_raciocinio_logico_e_algoritmos.md`](aula_01_raciocinio_logico_e_algoritmos.md) - Raciocínio lógico, pensamento computacional e algoritmos.

1. Definir o conceito formal de algoritmo.
2. Aplicar os 4 pilares do Pensamento Computacional (Decomposição, Reconhecimento de Padrões, Abstração e Algoritmos).
3. Entender a diferença entre código compilado e interpretado.
4. Executar scripts Python no terminal e interagir com Jupyter Notebooks.
