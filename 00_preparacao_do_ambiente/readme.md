# 🛠️ Módulo 00: Preparação do Ambiente e Ferramentas

Bem-vindo ao ponto de partida da nossa formação técnica! Todo desenvolvedor profissional precisa dominar o controle de versões e o fluxo de trabalho colaborativo antes de escrever grandes projetos.

### 📋 Conteúdo do Módulo:
* 📜 [`aula_01_git_e_github.md`](aula_01_git_e_github.md) - Versionamento de código, comandos essenciais do Git, branches e fluxo de entrega via GitHub.

### 🎯 Objetivos de Aprendizagem:
1. Compreender o que é controle de versão distribuído.
2. Configurar o Git localmente com nome e e-mail institucional.
3. Executar o ciclo de vida de alterações: `working directory` ➔ `staging area` ➔ `local repository` ➔ `remote repository`.
4. Utilizar mensagens de commit semânticas e claras.
