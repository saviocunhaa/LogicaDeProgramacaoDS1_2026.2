# 🧩 Módulo 05: Subprogramas, Funções e Escopo

Dividir para conquistar! Aprenda a modularizar seus algoritmos em blocos reutilizáveis com funções nomeadas, parâmetros, retornos, escopo e funções anônimas (lambda).

### 📋 Conteúdo do Módulo:
* 📓 [`aula_01_funcoes_nomeadas.ipynb`](aula_01_funcoes_nomeadas.ipynb) - Declaração com `def`, parâmetros, argumentos e `return` vs `print`.
* 📓 [`aula_02_funcoes_anonimas_e_escopo.ipynb`](aula_02_funcoes_anonimas_e_escopo.ipynb) - Expressões `lambda`, escopo de variáveis (LEGB) e palavra-chave `global`.
* 📓 [`desafio_04_refatoracao_investigativa.ipynb`](desafio_04_refatoracao_investigativa.ipynb) - Refatoração de código desorganizado em funções modulares.
* 📜 [`lista_04_exercicios.md`](lista_04_exercicios.md) - Lista com 5 missões práticas de funções e modularização.

### 🎯 Objetivos de Aprendizagem:
1. Criar subprogramas reutilizáveis com a palavra-chave `def`.
2. Diferenciar o retorno de dados (`return`) da simples exibição no console (`print`).
3. Compreender as regras de visibilidade e ciclo de vida de variáveis (escopo local vs. global).
4. Utilizar funções anônimas (`lambda`) para operações simples.
