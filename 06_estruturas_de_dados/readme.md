# 🗄️ Módulo 06: Estruturas de Dados e Coleções

Manipule conjuntos complexos de informações na memória do computador utilizando Listas, Tuplas, Matrizes, Dicionários e Conjuntos.

### 📋 Conteúdo do Módulo:
* 📓 [`aula_01_listas.ipynb`](aula_01_listas.ipynb) - Listas (`list`), indexação, métodos (`append`, `insert`, `pop`, `remove`, `sort`).
* 📓 [`aula_02_tuplas_e_matrizes.ipynb`](aula_02_tuplas_e_matrizes.ipynb) - Tuplas imutáveis (`tuple`) e matrizes bidimensionais.
* 📓 [`aula_03_dicionarios_e_conjuntos.ipynb`](aula_03_dicionarios_e_conjuntos.ipynb) - Dicionários chave-valor (`dict`) e conjuntos (`set`).
* 📓 [`desafio_05_inventario_suspeito.ipynb`](desafio_05_inventario_suspeito.ipynb) - Investigação de adulteração em inventário de equipamentos.
* 📜 [`lista_05_exercicios.md`](lista_05_exercicios.md) - Lista com 5 missões práticas de estruturas de dados.

### 🎯 Objetivos de Aprendizagem:
1. Criar e manipular listas dinâmicas com métodos de inserção e remoção.
2. Compreender a diferença entre mutabilidade (listas) e imutabilidade (tuplas).
3. Percorrer estruturas bidimensionais (matrizes).
4. Estruturar dados semi-estruturados com chaves e valores em dicionários.
5. Aplicar operações de teoria de conjuntos (união, interseção).
